Arcadium

Cornerstone of Engineering 1 — Final Project

Raspberry Pi Pico MicroPython AutoCAD Laser Cutting Circuit Design Prototyping

A portable, arcade-style reaction game built with the Raspberry Pi Pico. Arcadium addresses the need for simple, affordable, hands-on entertainment that engages users through electronics. The project features a circular LED array for gameplay, integrated LCD display for scoring, and a unique candy dispenser reward system—all housed in a custom laser-cut wood enclosure with acrylic viewing window.

How Arcadium Came Together

  1. Everyone prototyped their own game. Oct 28 – Nov 4
    Our team brainstormed six arcade-style game concepts. Each of the four of us picked one and built a working prototype of it: a flowchart, MicroPython code, an AutoCAD enclosure, and a laser-cut cardboard box. Mine was a Piano Tiles game.
  2. We picked one to build. Nov 18
    We compared all four prototypes on functionality, feasibility, and user experience, and chose Dabian’s Light Reaction Game as the base for our final product.
  3. We turned it into Arcadium. Nov 18 – Dec 5
    Together we scaled up the enclosure, rewired it for reliability, rebuilt it in laser-cut wood with an acrylic window, and added a candy dispenser reward, ready for the final showcase.

Technical Challenges Solved

Final Arcadium build (team)

  • Candy dispenser: Candy got stuck at the back, so we added a wood panel that pushes candy forward while leaving room for the dispensing platform to move
  • Servo stability: The servo shifted as it turned, so we laser-cut a custom bracket that holds it still and lets only the dispensing platform move
  • Curved enclosure: Created a flexible wood pattern with the laser cutter so flat plywood could bend into the cylinder
  • GPIO pins: Rewired to fit every component on a single Raspberry Pi Pico

My Piano Tiles prototype

  • Wire height: Wires stuck up too high and blocked the buttons, so I raised the buttons on a mini breadboard and switched to wires that sit flush
  • Muffled buzzer: Added a vent of small holes above the buzzer so the sound carries through the enclosure

Results & Peer Feedback

  • Delivered a portable, arcade-style game that runs entirely on a single Raspberry Pi Pico
  • Larger enclosure solved the component crowding of earlier prototypes while staying small enough to carry
  • Clean wiring layout reduced failure points and improved reliability
  • Rounds, levels, and the candy reward kept players engaged
  • Reinforced wood and acrylic structure made the final build durable

What we'd improve next, from peer feedback

  • Reduce button lag for faster response
  • Use a different or second Raspberry Pi so every LED in the ring lights up
  • Print instructions on the side of the enclosure so players can read them before powering on
