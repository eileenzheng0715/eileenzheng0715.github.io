ARCADIUM

Arcadium

Cornerstone of Engineering 1 - Final Project

A portable, arcade-style reaction game built with the Raspberry Pi Pico. Arcadium addresses the need for simple, affordable, hands-on entertainment that engages users through electronics. The project features a circular LED array for gameplay, integrated LCD display for scoring, and a unique candy dispenser reward system—all housed in a custom laser-cut wood enclosure with acrylic viewing window.

Raspberry Pi Pico MicroPython AutoCAD Laser Cutting Circuit Design Prototyping

Key Contributions

  • Designed and programmed Piano Tiles prototype using MicroPython for initial concept phase
  • Created custom AutoCAD enclosure designs optimized for component placement and user ergonomics
  • Engineered LCD display housing for final product integration
  • Collaborated on LED programming and candy dispenser mechanism troubleshooting
  • Documented full development process from brainstorming through final showcase

Technical Challenges Solved

  • Optimized wiring layout to minimize height and improve accessibility to buttons
  • Designed ventilation system for buzzer audio clarity within enclosed space
  • Solved candy dispensing mechanism with custom servo stabilization piece
  • Created flexible wood pattern using laser cutting for cylindrical enclosure construction
  • Managed GPIO pin constraints by rewiring to fit all components on single Raspberry Pi Pico

Design Process

  • Followed complete design thinking methodology from problem definition to solution
  • Iterated through multiple cardboard prototypes before final wood/acrylic construction
  • Integrated user feedback to enhance engagement through reward system
  • Balanced portability, durability, and functionality in final enclosure design
CADODILES

CADodiles

Trivia Dispenser — Cornerstone of Engineering 2 Final Project

An interactive STEM trivia game designed for fifth-grade classrooms, built with a team of five over five milestones. The system pairs a Raspberry Pi Zero-driven touchscreen trivia interface with a physical block-dispensing mechanism that rewards correct answers, all housed in a custom-painted laser-cut wood enclosure. The project addressed a real classroom need identified through stakeholder research: an inclusive, standards-aligned STEM game that stays engaging without relying on addictive reward loops.

Raspberry Pi Zero Python (Kivy) SolidWorks Laser Cutting Servo Motors Agile/Scrum User Research

Key Contributions

  • Served as Project Manager for Milestone 2, structuring the team's checklist, task distribution, and meeting cadence
  • Led market research on existing STEM educational games, identifying key gaps: poor curriculum alignment, limited collaboration/solo-only play, high cost, and no bilingual support — all of which directly shaped the team's design requirements
  • Contributed original game concept sketches during team ideation and helped narrow concepts using KTPA/KTDA decision matrices
  • Co-designed the dispenser in SolidWorks/AutoCAD (both interior mechanism and exterior enclosure), then laser-cut and assembled the physical dispenser box
  • Laser-cut, assembled, and hand-painted the game board alongside the dispenser, contributing hands-on fabrication across both major physical components
  • Maintained the team's design notebook and milestone documentation throughout the project

Technical Challenges Solved

  • Dispenser mechanism: Originally designed around a 3D-printed platform jack, but discovered mid-build that it couldn't be scaled down enough to fit inside the dispenser without oversizing the whole enclosure — scrapped the mechanism and redesigned the interior around a servo-driven waterwheel instead
  • Dispenser mechanism: After switching to the waterwheel, diagnosed the MG90S servo's 180° rotation limit (not the assumed 360°) and revised the control logic to oscillate clockwise/counterclockwise instead of rotating continuously
  • Dispenser mechanism: Identified insufficient clearance for the LCD's HDMI cable and extended the enclosure by 4 inches, and added a bottom access door after realizing students had no way to retrieve dispensed reward pieces
  • Game board: First laser-cut version left the board misaligned where the base and angled panels met because the CAD didn't account for the plywood's actual thickness; corrected the model and re-cut, using multiple clamps during glue-up to keep every panel flush
  • Blocks: Standardized all game piece dimensions (0.5" per unit) against a single reference drawing so blocks, the dispenser opening, and the game board all fit together consistently across separate laser-cut parts
  • System integration: Integrated a Raspberry Pi Zero, touchscreen LCD, servo, and LED strip within a single compact enclosure

Design Process

  • Grounded design decisions in a formal problem statement built from direct research with fifth-grade stakeholders and teachers
  • Evaluated concept alternatives with weighted decision matrices (KTPA/KTDA) against portability, cost, and intuitiveness criteria
  • Iterated through cardboard prototypes, an intermediate gameboard version, and a final painted wood/acrylic enclosure across five milestones
  • Rebuilt the dispenser's internal mechanism from scratch mid-project after the initial platform jack design proved unworkable at the required scale
  • Re-fabricated the game board after the first laser-cut version revealed a design-to-manufacturing gap between CAD and actual material thickness
  • Coordinated dimensions across three separately-built components (dispenser, board, blocks) so they assembled into one consistent system
  • Designed the reward mechanism to be fully deterministic (fixed pieces dispensed per correct answer, no randomness) — directly addressing the "addictive/unfair reward loop" gap identified during market research
  • Ran the project using sprint-based backlogs, tracking tasks and blockers milestone to milestone

Results & Validation

  • Tested the completed prototype live with six groups of actual 5th-grade students at Melrose Leadership Academy — the system's real target users, not just classmates
  • System powered on and reached playable gameplay in 2–3 minutes with no jamming or failures observed during testing
  • Passed a formal two-person safety inspection (no sharp edges, no exposed wiring, no choking hazards) prior to student use
  • Delivered under budget: $86.57 actual cost vs. $119.57 theoretical, using shared Makerspace resources and an already-owned Raspberry Pi
  • Observed students collaborating, forming informal teams, and voluntarily attempting extra questions — evidence the design met its engagement and collaboration goals
